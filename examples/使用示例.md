
# Audio Transcription Examples

## Example 1: Video transcription

Input:

```text
/Users/username/Movies/interview.mp4
```

Command:

```bash
asr "/Users/username/Movies/interview.mp4" \
--out "/Users/username/Movies/interview.txt"
```

Output:

```text
说话人1：大家好，欢迎参加今天的会议。

说话人2：谢谢，今天我们主要讨论项目进度。

说话人1：首先介绍一下目前的工作情况。
```

## Example 2: Audio with timestamps

Command:

```bash
asr meeting.mp3 --timestamps --out meeting.txt
```

Output:

```text
[00:00:01,200 -> 00:00:06,360] 说话人0：大家好。

[00:00:07,340 -> 00:00:12,180] 说话人1：我们开始今天的会议。
```

## Example 3: Disable speaker separation

```bash
asr interview.mp4 --no-speakers --out interview.txt
```

## Notes

The actual transcription output depends on audio quality, language, model availability and API service response.
